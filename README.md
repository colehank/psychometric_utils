# Psychometric - 心理测量学问卷指标计算库

一个简单心理测量学库，包括项目分析、信度分析和效度分析。

- **项目分析（Item Analysis）**
  - 难易度分析（均值/通过率）
  - 校正题总相关（CITC）
  - 极端组检验

- **信度分析（Reliability Analysis）**
  - Cronbach's α系数
  - McDonald's Omega系数
  - 分半信度
  - 删除题目后的α分析

- **效度分析（Validity Analysis）**
  - 探索性因子分析（EFA）
  - 验证性因子分析（CFA）
  - 平均方差提取（AVE）
  - 组合信度（CR）
  - 判别效度分析

## 安装

使用uv安装：

```bash
uv add psychometric
```
